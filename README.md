# Patienten-Anfrageformular

Prototyp aus dem Mini-Hackathon beim Ophthalmologen-Kongress (25.–26.09.2026).

**Live:** https://niclasbayer.github.io/patienten-anfrage/

Anfrageformular für refraktive Beratung, das hinter Social-Media- und Werbekampagnen
liegt: Vier Ja/Nein-Fragen filtern vorab, wer für eine refraktive Beratung geeignet ist.
Geeignete Patienten buchen direkt einen Termin, alle anderen bekommen einen regulären
Vorsorgetermin angeboten. Dazu eine Praxis-Ansicht mit den gebuchten Terminen.

React + Vite, läuft komplett im Browser. Alle Beispieldaten sind **synthetisch** —
keine echten Patientendaten.

Lokal starten: `npm install && npm run dev` → http://localhost:8080
